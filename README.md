### Задача 2. Маршрут по участкам

Дорога состоит из нескольких участков, известны их длины и средние скорости автомобиля на каждом участке. Автомобиль въехал на дорогу в начале участка `k` и выехал после участка `p`. Определите:

1. длину пути с `k` по `p` участок;
2. время в пути;
3. среднюю скорость на всём пройденном отрезке;
4. **номер участка и расстояние от его начала**, на котором автомобиль окажется через `t` часов после въезда.

Входные данные (с клавиатуры): строка длин, строка скоростей, `k`, `p`, `t`.

Тест:

```
Длины:    12 7 15 9 20 11 6 14 10 8
Скорости: 40 60 50 45 70 35 55 65 50 60
k = 3, p = 8, t = 1
S = 75 км, T = 1.42 ч, V = 52.65 км/ч
Через 1 ч автомобиль на участке 6, в 7.5 км от его начала
```

Программа должна быть **устойчива к некорректному вводу** (буквы вместо чисел, `k > p`, номера вне диапазона, разное число длин и скоростей, `t` больше общего времени в пути): никаких traceback — понятное сообщение и повторный запрос данных.

### Задача 3. СЛАУ матричным способом

Решите систему линейных уравнений:

```
 4x₁ − 1.5x₂ + 2x₃ + 0.5x₄ = 11.05
  x₁ +   5x₂ − 2x₃ + 1.2x₄ = −6.82
−2x₁ +   x₂ + 6x₃ −   x₄ = 11.5
0.5x₁ +  2x₂ −  x₃ +  7x₄ = −0.5
```

Необходимо:

- сформировать матрицу `A` и вектор-столбец `B`;
- проверить, что `det(A) ≠ 0`, и вывести число обусловленности `np.linalg.cond(A)`;
- вычислить решение по формуле `X = A⁻¹ · B`, а затем с помощью `np.linalg.solve`;
- сравнить результаты (норма разности) и выполнить **проверку** подстановкой: `‖A·X − B‖`;
- вывести вектор решения, округлив значения до одного знака после запятой.

Ожидаемый ответ: `[ 1.2 -0.7  2.5  0.4 ]`.

## Часть 3. Генерация синтетических данных

### Описание данных

Разработайте CLI-скрипт `generate_data.py`, который генерирует **посуточные данные о продажах сети магазинов за 3 года** и сохраняет их в CSV. Запись соответствует продаже одного товара в одном магазине за один день.

Поля:

| Поле | Описание |
|------|----------|
| `date` | Дата |
| `store_id` | Идентификатор магазина (не менее 5 магазинов) |
| `city` | Город магазина |
| `category` / `product` | Категория и товар (не менее 3 категорий и 8 товаров) |
| `qty` | Проданное количество |
| `price` | Средняя цена продажи |
| `cost` | Себестоимость единицы |
| `promo` | Флаг акции (0/1) |
| `payment_method` | Способ оплаты (наличные / карта / онлайн) |

Закономерности, которые **обязательно** должны быть заложены в данные:

- тренд (рост или спад) для разных товаров разный;
- недельная сезонность (выходные ≠ будни) и годовая сезонность (минимум для одной категории);
- влияние акций на `qty` и `price`;
- случайный шум и не менее 1% выбросов/аномалий;
- не менее 0.5% пропусков в `price` или `payment_method`.

### Требования к скрипту

- Параметры командной строки (`argparse`): `--seed`, `--years`, `--stores`, `--out`.
- Результат **воспроизводим**: один и тот же `--seed` даёт идентичный файл.
- Некорректные параметры (отрицательное число лет, пустое имя файла, нет прав на запись и т. п.) не приводят к traceback: выводится понятное сообщение и код возврата ≠ 0. Для типовых ошибок опишите собственные исключения (например, `InvalidConfigError`).
- Функции генерации вынесены отдельно от `main()` и снабжены docstring.

### Визуализация

В `visualize.ipynb` по сгенерированным данным постройте графики, **используя не менее трёх разных библиотек визуализации** (например, Matplotlib, Seaborn, Plotly):

- динамика выручки по месяцам (общая и по категориям);
- динамика средней цены по каждой категории;
- объём продаж по магазинам и городам;
- распределение продаж по дням недели;
- структура способов оплаты;
- влияние акций на объём продаж (до/во время/после).

### Анализ

Подготовка данных:

Агрегируйте продажи по неделям для каждой категории.

### Прогноз

Методы прогнозирования (выберите 2 из 3):
- Сезонный наивный прогноз — прогноз на следующую неделю равен значению за аналогичную неделю прошлого года (или прошлого месяца, если годовых данных мало).
  ```
  
   # Пример: прогноз = значение 52 недели назад
   forecast = sales.shift(52)
  ```
- Скользящее среднее — прогноз равен среднему за последние N недель (N = 4 или 8).
  ```

   # Пример: скользящее среднее за 4 недели
   forecast = sales.rolling(window=4).mean().shift(1)
  ```
- Линейный тренд — аппроксимируйте данные прямой линией и экстраполируйте
  ```

   from numpy.polynomial import Polynomial
   # или sklearn.linear_model.LinearRegression
   x = np.arange(len(sales))
   coeffs = np.polyfit(x, sales, deg=1)
   forecast_trend = np.polyval(coeffs, x + 8)
  ```

Постройте график «факт vs прогноз» для каждой категории.
Вычислите одну метрику качества: MAE (Mean Absolute Error) или MAPE (Mean Absolute Percentage Error).

```
   mae = np.mean(np.abs(actual - predicted))
   mape = np.mean(np.abs((actual - predicted) / actual)) * 100
```
